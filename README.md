# ApplyCue

**Know your next move.** A Python/Django job-application planner in development,
inspired by the graduate job search.

## Repository status

This public repository currently contains planning documents. The Django
implementation is being developed locally and has not yet been published here.
There is no runnable application in this checkout.

The latest verified local checkpoint contains user-owned application records,
login/logout and a private application list. Three tests cover anonymous access,
ownership filtering and the empty state. A user-facing creation form is still
in progress; it is not an available public feature.

The intended sequence is a complete manual application workflow, followed by
reviewable email-derived updates. Gmail integration and AI extraction remain
planned work, not completed capabilities.
